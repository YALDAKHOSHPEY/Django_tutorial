## 📖 About

This repository is a hands-on learning path for the Django framework. It covers everything from the initial setup to building web pages, managing databases, and deployment — all through practical, real-world steps.

The goal is to help you understand core Django concepts by building an actual project.

---

## ✨ Features

- ✅ Django 5.0.9 installation and setup
- ✅ Standard project and app structure
- ✅ URL routing and Views
- ✅ Working with Templates
- ✅ Models and Database (ORM)
- ✅ Django Admin Panel
- ✅ Static file management

## 🛠️ Prerequisites
